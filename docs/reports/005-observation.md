# 과제 5 직접 관찰 채점

`python -m state observe`가 만든 표. 만든 시각 2026-10-22 08:33 UTC. 해석은 [005-state.md](005-state.md).

## 측정 조건

| 항목 | 값 |
|---|---|
| 데이터 | 실데이터, 수집기가 MQTT로 실시간 저장한 값 (합성 아님) |
| 정답 | 사람이 직접 본 인원 (`docs/observations/occupancy.csv`, 3구간) → 0명이면 비어있음, 1명 이상이면 사용중 |
| 입력 | 그 시간 실시간 수집기 DB(`collector.db`), 학습 때와 같은 전처리(`pipeline.preprocess`) |
| 그림 구간 | 2026-10-22 09:10 ~ 12:15 KST (관찰 2시간 전부터, 15·60분 변화 계산용) |
| 모델 | 과제 5 사용 여부 분류기(센서만, 임계값 0.95, 검증 기간으로 정함). 다시 학습하지 않음 |
| 규칙 | 15분 CO₂ 변화 ≥ +30 ppm |
| 일정 | `config/schedule.toml` 실습실 평일 09:00~11:30·13:00~18:00 (점심 11:30~13:00은 0.5로 보고 비교에서 뺌) |
| 칸 | 5분, 관찰 구간 안의 칸 6개 (사용중 6, 비어있음 0) |

> **비어있음 관찰이 아직 없다.** 그래서 '비어있음→사용중' 오류율과 정밀도는 계산할 수 없고(표의 `-`),
> 지금 숫자는 '사람이 있을 때 알아보는가'(재현율)만 말해 준다. 퇴실 뒤나 점심의 빈 방을 관찰해 추가해야 한다.
