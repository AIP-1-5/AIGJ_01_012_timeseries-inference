# Implementation Plan: 과제 4 — 이상 탐지

**Spec**: [spec.md](./spec.md) | **Date**: 2026-10-21

## Summary

과제 2 정제 데이터를 그대로 쓰고, 검증·시험 기간 복사본에 고장 5종을 심는다(`anomaly/inject.py`). 학습 기간 정상 창(1시간 = 12칸, co2·temperature·humidity의 정규화 값과 5분 변화량 + 하루 시각·일정 있는 날)으로 작은 MLP 오토인코더를 학습하고 재구성 오차를 점수로 쓴다. 규칙 5종의 기준값은 학습 기간에서 정한다. 임계값과 경보 묶기는 고장을 심은 검증 복사본으로 정하고(헛경보 하루 1회 이하 안에서 탐지율 최대), 다른 씨앗으로 심은 시험 기간에서 한 번 평가한다.

## Technical Context

- Python 3.12, torch(과제 3과 같음), pandas. 패키지 `anomaly/`, CLI `python -m anomaly` (`./anomaly.sh`)
- 학습·평가는 보드 B(데이터가 있는 곳) 또는 맥. 모델 파라미터 1만 개 수준
- 결과: `docs/reports/004-detection.md`(자동 표), `004-anomaly.md`(해석), `figures/004-*.png`. 모델·고장 데이터는 `data/anomaly/`(커밋 안 함)

## Design

| 구성 | 결정 |
|---|---|
| 주입 | 튄 값: 한 칸 ±(CO₂ 400~1,200 ppm, 온도 4~8℃). 값 고정: 1~4시간 직전 값 반복. 영점 틀어짐: CO₂ 6시간 동안 +200~500 ppm 선형 상승 후 6시간 유지. 냉방 정지: 수업 시간 온도 2시간 동안 +3~5℃ 선형 상승 후 수업 끝까지 유지. 환기 정지: 수업 블록 동안 CO₂ = 기준 + 1.8 × (값 − 기준), 기준 = 블록 시작 전 30분 평균 |
| 모델 | 입력 12칸 × (z 3 + Δz 3) + 시각 sin·cos + 일정 있는 날 → 64 → 16 → 64 → 36(z·Δz 재구성). 점수 = 마지막 3칸 평균 절대 오차, 항목별 오차로 원인 |
| 규칙 | 급변: |Δ| > 학습 기간 99.99% × 1.5 이고 다음 칸에서 되돌아옴. 값 고정: CO₂·습도가 N칸 동안 완전히 같음(N은 학습 기간 정상 최장 × 1.5). 영점 틀어짐: 22~07시 CO₂ 2시간 상승 > 학습 기간 99.9%. 냉방 정지: 수업 시간 온도 − 같은 시각 최근 정상 중앙값 > 학습 기간 99.9%. 환기 정지: 수업 시간 CO₂ > 같은 시각대 학습 기간 99.5% |
| 경보 | 점수 > 임계값인 칸 → 30분 안의 경보를 한 이벤트로 묶음, 같은 공간 재경보 간격 60분 |
| 매칭 | 고장 구간(+유예 60분)과 겹치면 탐지. 지연 = 첫 경보 − 고장 시작 |
| 임계값 | 검증 복사본에서 헛경보 ≤ 0.5회/일(여유) 안에서 결합 탐지율 최대 |

## Risks

| 위험 | 대응 |
|---|---|
| 합성 고장이 실제와 다름 | 과제 문서 표의 모습을 그대로 따르고 크기를 범위로 뽑는다. 키트가 오면 키트 고장으로 다시 평가 |
| 헛경보가 많음 | 검증 기준 임계값, 경보 묶기, 공간별 임계값 제안 |
| 값 고정이 정상 범위 안이면 모델이 못 잡음 | 규칙으로 보완(생각해 볼 점 1의 답) |
