# Feature Specification: 과제 5 — 상태 추정

**Feature Branch**: `005-state-estimation` | **Created**: 2026-10-21 | **Status**: Draft

**Input**: "과제 5. 센서값만으로 공간 사용 여부를 추정하고, 30분 안 1,000ppm 초과를 미리 알리는 분류기를 만든다."

## 완료 조건 (과제 5 확인 기준, 원문 그대로)

1. 사용 여부 추정: 직접 관찰한 시간대 기준 정확도와 F1을 보고한다. '비어있음'인데 '사용중'으로 판단하는 오류율을 따로 보고한다(냉난방 자동 제어에서 가장 중요). 단순 규칙보다 좋아야 한다
2. 환기 경보: '곧 환기 필요' 재현율 **85% 이상**, 단순 규칙보다 macro-F1이 높다
3. 혼동 행렬을 보고 가장 많이 헷갈리는 경우를 설명한다

## 정답 정의

- **사용 여부**: 실습실 일정(평일 09:00~11:30, 13:00~18:00, 공휴일 제외) = 사용중, 그 밖 = 비어있음. 점심(11:30~13:00)은 1~3명이 남을 수 있어(사용자 제보) 학습·일정 기준 평가에서 뺀다. 일정 변화 직후 15분도 사람이 드나드는 중이라 학습에서 뺀다.
  - 일정 기반 정답은 틀릴 수 있다: 과제 2에서 일정 없는 날 사용 64일, 일정 있는데 비어 있던 날 2일을 찾았다. 직접 관찰 기록(`docs/observations/occupancy.csv`)으로 일정 기반 정답이 얼마나 틀리는지 확인한다.
  - 회의실·사무실은 일정·예약 자료가 없어 정답을 만들 수 없다. 실습실로 학습한 모델을 적용해 결과만 보이고(심화 B: 학습하지 않은 공간), 관찰 기록이 있으면 평가한다.
- **환기 경보 양성**: 지금 CO₂ < 1,000 ppm이고, 앞으로 30분 안(t+5 ~ t+30분)에 1,000 ppm 이상이 되는 시각. 이미 1,000 ppm 이상인 시각은 표본에서 뺀다 — 넣으면 "지금 높다"만 보고도 맞히는 쉬운 표본이 섞여 재현율이 부풀고, 정작 필요한 "넘기 전" 경보 성능을 가린다.

## 입력

- **사용 여부**: 센서값만(CO₂·온도·습도의 수준과 5·15·30·60분 변화). 시각·요일·일정은 넣지 않는다 — 정답을 일정에서 만들었으므로 입력에 넣으면 모델이 센서가 아니라 시계를 보고 정답을 외운다. 일정 기반 점수는 거의 완벽해지지만, 일정과 다른 날(주말 사용, 휴강)에는 그대로 틀린다.
- **환기 경보**: 센서값 + 시각·요일·일정(미래에 알 수 있는 정보라 써도 된다).

## User Scenarios & Testing

- **US1 (P1) 사용 여부 분류기**: 학습 기간 일정 기반 정답으로 학습, 검증으로 임계값, 시험 기간(일정 기준)과 직접 관찰 시간대에서 평가. 단순 규칙("최근 15분 CO₂ 30 ppm 이상 상승이면 사용중")과 비교.
- **US2 (P1) 환기 경보 분류기**: 공간 3곳(CO₂ 있는 곳). 검증 기간에서 재현율 ≥ 85%를 지키는 임계값 중 macro-F1 최대. 단순 규칙("현재 CO₂ ≥ 850 ppm이면 경보")과 비교. 정확도가 왜 의미 없는지 보인다.
- **US3 (P1) 혼동 행렬과 사례 분석**: 가장 많이 틀리는 상황(시간대·공간·이유).
- **US4 (P2) 일정 기반 정답 vs 직접 관찰**: 관찰 기록이 있으면 일치율, 없으면 과제 2의 어긋난 날로 대신 추정하고 관찰 양식을 남긴다.

## Requirements

- FR-001 과제 2 정제 결과·분할·정규화 재사용. 학습은 학습 기간, 임계값은 검증 기간, 시험 기간은 한 번.
- FR-002 사용 여부 입력에 시각·요일·일정을 넣지 않는다(자동 시험).
- FR-003 환기 경보 표본에서 이미 1,000 ppm 이상인 시각을 뺀다(자동 시험).
- FR-004 성적표: 정확도, 정밀도, 재현율, F1, macro-F1, 비어있음→사용중 오류율, 혼동 행렬. 모델 vs 규칙.
- FR-005 측정 조건 블록.

## Success Criteria

- SC-001 사용 여부: 직접 관찰 시간대(없으면 시험 기간 일정 기준) 정확도·F1·비어있음→사용중 오류율을 보고, 규칙보다 F1이 높다
- SC-002 환기 경보: 시험 기간 재현율 ≥ 85%, macro-F1 > 규칙
- SC-003 혼동 행렬과 가장 많이 헷갈리는 경우의 설명

## Assumptions

- 분류기는 그래디언트 부스팅(scikit-learn HistGradientBoosting). 작고 빠르며 과제 7·8에서 CPU로 충분하다(트리 모델은 TensorRT 대상이 아니므로 과제 7은 예측·이상 탐지 모델 위주).
- 직접 관찰은 사람이 해야 한다. 양식 `docs/observations/occupancy_template.csv`.
