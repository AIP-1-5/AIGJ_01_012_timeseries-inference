# Feature Specification: 과제 6 — 사전학습 모델 비교

**Feature Branch**: `006-pretrained` | **Created**: 2026-10-21 | **Status**: Draft

## 완료 조건 (과제 6 확인 기준, 원문 그대로)

1. 세 방법을 같은 시점에서 비교했다
2. 정확도, 예측 구간 적중률, 추론 시간, 메모리 네 가지로 판단 근거를 제시한다

## 범위

- 사전학습 모델: Chronos-Bolt tiny(약 900만)·small(약 4,800만 파라미터). 추가 학습 없이 CO₂ 과거값만 넣어 60분(12칸) 예측, 분위 10·50·90%.
- 세 방법: 기준선(과제 2) · 직접 학습한 모델(과제 3에서 고른 GRU) · 사전학습 모델. 같은 `artifacts/eval_points.csv`, 같은 관측 정답.
- 과거 길이(4시간·1일·2일)는 **검증 기간**으로 고르고, 시험 기간은 모든 길이를 보고한다(생각해 볼 점 "과거를 얼마나 길게").
- 예측 구간 적중률 = 실제값이 10~90% 구간 안에 든 비율(이상적 80%).
- 비용: 보드 B에서 1회 추론 시간(배치 1·4, 평균·p95, 워밍업 5·반복 50)과 메모리 증가(RSS). 보드 B에는 CUDA판 PyTorch가 없어 CPU로 잰다(측정 조건에 적음).
- 채택 의견(반 쪽): 정확도·구간·시간·메모리와 로컬 LLM(W4)과의 메모리 예산.

## Success Criteria

- SC-001 비교표에 세 방법의 h별 MAE와 같은 평가 시점 수
- SC-002 적중률, 배치 1·4 지연, 메모리 증가가 표에 있고, 채택 의견이 네 근거로 쓰여 있다

## Assumptions

- Hugging Face에서 모델을 내려받는다(보드 B 인터넷 확인됨). 클라우드 작업 환경은 Hugging Face에 닿지 않아 가짜 모델로 평가 경로만 시험한다.
